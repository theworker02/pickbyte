# pickbyte

Pick structured JSON byte payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/pickbyte/

## Install / run

```bash
git clone https://github.com/theworker02/pickbyte.git
cd pickbyte
node src/cli.js
node --test
```
